Nail 0.8, a preview for Windows.

- Import from Thunderbird, mbox, Maildir, .eml, .ics and .vcf; export to the same formats.
- Encrypted backups with a dry run before restoring.
- The whole database is encrypted with encryption at rest; a recovery key gets your data back.
- Smartcards and tokens for S/MIME and OpenPGP.
- Command palette (Ctrl+K), printing and Save as PDF, a diagnostics bundle for support.
- Exchange: large attachments, sending from shared mailboxes, sync policies; Gmail and Exchange conversations.

Please keep a backup of your data while testing a preview.
