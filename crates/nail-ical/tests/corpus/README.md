# nail-ical test corpus

Calendar and contact files in the shapes the common producers export,
used by `tests/corpus.rs` (WP71, ADR 0059).

**Everything here is synthesized.** The files were written by hand to
mimic the structure, property order, vendor extensions, folding and
quirks of real exports; they contain no real people, accounts or
meetings. Names are historical figures, addresses use reserved example
domains (`example.org`, `.example`), phone numbers use fictional ranges
(UK 07700 900xxx, US 555-01xx), and UIDs are made up.

| Folder | Mimics | What it exercises |
| --- | --- | --- |
| `google/calendar-export.ics` | Google Calendar "Export" (`PRODID:-//Google Inc//Google Calendar 70.9054//EN`) | `X-WR-*` headers, IANA `VTIMEZONE` with `X-LIC-LOCATION`, weekly series with `UNTIL` in UTC, `EXDATE`s, a moved occurrence (`RECURRENCE-ID`), `X-NUM-GUESTS`, `X-GOOGLE-CONFERENCE`, the Meet footer in `DESCRIPTION`, yearly all-day birthday, Drive attachment, Zoom link in `LOCATION`, empty `LOCATION:` / `DESCRIPTION:` |
| `google/contacts.vcf` | Google Contacts vCard 3.0 export | `TYPE=INTERNET`, grouped `item1.URL` + `X-ABLabel`, escaped `https\://`, `X-ABDATE` / `X-ABRELATEDNAMES` with Apple labels, `CATEGORIES:myContacts` |
| `outlook/calendar-export.ics` | Outlook 2016 "Save as iCalendar" | Windows zone `W. Europe Standard Time` (quoted `TZID` parameters), a `Customized Time Zone` that matches New York only by its rules, `X-MICROSOFT-CDO-*`, `X-ALT-DESC` HTML, Teams links (`X-MICROSOFT-SKYPETEAMSMEETINGURL` and in the text), `SUMMARY;LANGUAGE=`, a resource attendee, `BYSETPOS`, all-day events with `TRANSPARENT`, long UIDs folded |
| `outlook/contacts-vcard21.vcf` | Outlook "Save as vCard" (vCard 2.1, **Windows-1252 bytes**) | bare types (`TEL;WORK;VOICE`), `QUOTED-PRINTABLE` with soft line breaks, `CHARSET`, `LABEL`, `X-MS-OL-*`; generated by `outlook/generate.py` (not needed at test time) |
| `apple/icloud-calendar.ics` | macOS Calendar / iCloud | `X-APPLE-CALENDAR-COLOR`, `X-APPLE-STRUCTURED-LOCATION` with quoted parameters, `VALARM` with `X-WR-ALARMUID` / `UID` / `ACKNOWLEDGED` (RFC 9074), an `ACTION:NONE` default alarm, an event in the night the clocks go back, last day of every month |
| `apple/reminders.ics` | iOS Reminders over CalDAV | `VTODO`s with `X-APPLE-SORT-ORDER`, subtasks (`RELATED-TO;RELTYPE=PARENT`), absolute alarm, completed task, recurring task with a zone that has no `VTIMEZONE` |
| `apple/contacts.vcf` | macOS Contacts vCard 3.0 | `item` groups with `_$!<Mobile>!$_` labels, `type=pref`, `X-APPLE-OMIT-YEAR`, `X-ABRELATEDNAMES`, `X-SOCIALPROFILE`, inline JPEG photo (`ENCODING=b`, folded), an Apple group (`X-ADDRESSBOOKSERVER-KIND` / `-MEMBER`) |
| `thunderbird/calendar-export.ics` | Thunderbird 128 "Export" | `X-TZINFO` zones with `RDATE` observances, an old `/mozilla.org/…` `TZID`, `X-MOZ-*` (snooze, last ack), `EXDATE` in UTC against a zoned series, an override, `VTODO` with `RELATED=END` alarm and a subtask without `RELTYPE` |
| `thunderbird/address-book.vcf` | Thunderbird 128 address book (vCard 4.0) | `PREF=1`, `VALUE=TEXT` phones, `IMPP`, `ANNIVERSARY:--0612`, `KIND:group` with `MEMBER` (uuid and mailto), `X-CUSTOM1` |
| `feeds/holidays.ics` | a public holiday feed (`webcal:`) | `X-WR-TIMEZONE` for floating times, `REFRESH-INTERVAL` + `X-PUBLISHED-TTL`, `COLOR`, `DURATION` of weeks |
| `edge/rfc-edge-cases.ics` | RFC 5545 corner cases | `RANGE=THISANDFUTURE`, a start inside the spring-forward gap, `RDATE;VALUE=PERIOD`, lower-case names, quoted `:` / `;` in parameters, an unknown sub-component, an unknown `TZID`, a `VJOURNAL` (ignored, kept), `BYSETPOS=-1` |
| `edge/lf-line-endings.vcf` | web exports with bare LF | LF-only line endings (kept with `-text` in `.gitattributes` here) |

The `.gitattributes` in this folder keeps every file byte for byte (CRLF
endings, Windows-1252), because the tests check that unchanged items are
written back exactly as they were read.
